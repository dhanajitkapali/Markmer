The problem

Every AI tool writes Markdown. macOS reads it as plain text.

Claude, ChatGPT, Copilot and Cursor hand you README.md, PLAN.md and notes full of diagrams. Double-click one on a Mac and you get TextEdit showing raw symbols, or Xcode grinding to life.

Without Markmer

TextEdit opens the file. Headings are pound signs, tables are pipes, and the diagram is a wall of arrows.

With Markmer

The same file opens as a formatted page: real headings, a real table, syntax-highlighted code and the diagram drawn as a diagram. Edit the file in your editor and Markmer re-renders in place.

open -a Markmer PLAN.md   # or just double-click it
Mermaid, built in

Diagrams render inline. No plugin, no browser tab.

A ```mermaid fence becomes a drawing, themed to match light or dark mode. If a diagram has a syntax error, Markmer shows the error and the source instead of a blank box.

Lightweight

Smaller than most screenshots.

Markmer is native SwiftUI on top of the WebKit that already ships with macOS. There is no bundled browser, no runtime, no background service.

Not Electron. Electron apps ship their own copy of Chromium, so a Markdown viewer weighs in at 100 MB or more before you open a file. Markmer uses the system WebKit and stays around 2 MB.

Opens instantly. A universal binary for Apple Silicon and Intel, one window, and a sidebar of recent files. Launch it, read, close it.

Nothing phones home. The renderer loads marked, mermaid and highlight.js from jsDelivr. Prefer fully offline? Run Tools/vendor.sh once and build with the libraries bundled.

Readable source. Five Swift files and one HTML template. If you can read Swift, you can audit the whole app in an afternoon.

Install

Three steps. One extra click the first time.

Markmer is free and has no Apple Developer subscription behind it, so it is not notarized. macOS asks you to confirm once. After that it opens like any other app.

Download and unzip

Grab Markmer-<version>.zip from the latest release and unzip it.

Move to Applications

Drag Markmer.app into your Applications folder.

Open Anyway

On first launch macOS refuses. Open System Settings → Privacy & Security, scroll down, click Open Anyway, confirm. Or run once:

xattr -dr com.apple.quarantine /Applications/Markmer.app
Want .md files to open in Markmer by default? Right-click any Markdown file in Finder, choose Get Info, pick Markmer under Open with, and click Change All…. Every release is built by GitHub Actions from the tagged commit, and ships a .sha256 file you can verify against.
Markmer is open source. Source, issues and releases on GitHub. Built with SwiftUI and WebKit. Diagrams by Mermaid.
