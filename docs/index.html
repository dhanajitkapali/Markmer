Features

Everything a reader needs. Nothing it doesn't.

One window, a sidebar of recent files, and a renderer that gets out of your way. Markmer is a viewer, not another editor.

Mermaid, built in

A ```mermaid fence becomes a drawing. Every diagram type Mermaid supports, themed to match. Broken syntax shows the error and source instead of a blank box.

Absurdly light

Native SwiftUI on the WebKit already in macOS. No bundled browser, no runtime.

Live reload

Save in your editor, or let your AI agent rewrite the file. Markmer re-renders in place and keeps your scroll position.

GitHub-flavoured Markdown

Tables, task lists, strikethrough, autolinks, and fenced code with syntax highlighting. Styled the way GitHub renders it, because that is what you expect.

Keyboard first

Open, zoom, reset, and jump through recents without touching the mouse. Zoom level is remembered.

⌘Oopen
⌘=zoom in
⌘−zoom out
⌘0reset

Recents sidebar

Every file you open is one click away. Searchable, persistent across launches, hideable when you want the page to yourself.

Opens from anywhere

Double-click in Finder, drop a file on the window, ⌘O, File ▸ Open Recent, or from the terminal: open -a Markmer README.md

Install

Thirty seconds. One extra click the first time.

Markmer is free and has no Apple Developer subscription behind it, so it is not notarized. macOS asks you to confirm once, then it opens like any other app.

Download and unzip

Grab the zip with the button on this page, or from the Releases page. Double-click to unzip. Homebrew user? One command does steps 1 and 2:

$ brew install --cask dhanajitkapali/tap/markmer

Move to Applications

Drag Markmer.app into your Applications folder.

Allow it once

On first launch macOS refuses. Open System Settings → Privacy & Security, scroll down, click Open Anyway. Or skip the dialog entirely:

$ xattr -dr com.apple.quarantine /Applications/Markmer.app

Make it the default for .md

Right-click any Markdown file in Finder → Get Info → Open with: Markmer → Change All… From then on, double-click just works.

$ open -a Markmer README.md
